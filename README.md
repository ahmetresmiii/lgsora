# lgsoraLGSora — LGS çalışma uygulaması prototipi

Kullanım:
1. index.html dosyasını tarayıcıda aç.
2. İlk giriş ekranında profil bilgilerini doldur.
3. Dersler > Türkçe > Sözcükte Anlam bölümünden Vimeo derslerini aç.

Not: Vimeo videoları player.vimeo.com iframe ile gömülüdür. İnternet bağlantısı gerekir.
